# Chord Sheet Studio

Turn a chord progression into a printable A4 chord sheet — guitar diagrams, keyboard
diagrams with fingering, and the progression table — for songwriters, teachers and
classroom use.

**[Open Chord Sheet Studio →](https://rayfoolshs.github.io/chord-sheet-maker/)**

Made by Ray Foo · [www.rayfooproductions.com](https://www.rayfooproductions.com)

---

## What it does

Type a progression (up to 12 rows × 8 chords) and the app renders a sheet you can print or
save as PDF:

- **Guitar** — chord diagrams with fingering, using curated open shapes where they exist and
  movable E-/A-shape barre chords otherwise, with automatic barre detection.
- **Keyboard** — chord tones mapped to one octave with right/left-hand fingering.
- **Progression table** — the chords laid out as a chart, with the song title and key.

Chords are validated as you type and normalised on blur; invalid entries highlight red with
a tooltip rather than being silently accepted.

## Chord support

Root `[A–G]` with `#`, `b`, `♯`, `♭`, optional slash bass, and the qualities: major, minor,
7, maj7, m7, m9, maj9, 9, 6, m6, add9, madd9, sus2, sus4, dim, dim7, aug, 5 — with aliases
(`min`, `-`, `M7`, `Δ7`, `°`, `+`, `sus`).

## Using it

1. Type the song title (optional — falls back to "Untitled Song").
2. Enter chords into the grid. `Space` or `Enter` moves to the next slot and adds a row at
   the end when you run out.
3. Toggle the Guitar and Keyboard sections on or off.
4. Choose how many chords per row and which hand to show for piano fingering.
5. **Print / Save PDF** produces the A4 sheet.

Everything is stored in the browser, so a refresh keeps your work.

### Printing on an iPad

iPadOS does not reliably give web apps a print dialog, so on any iPad the app builds a
one-page A4 PDF of your sheet and shows a preview with Share / Print PDF and Download PDF.
Tap **Share / Print PDF** and choose **Print** or **Save to Files**; if the share sheet does
not open, press and hold the preview to save it to Photos, or use **Download PDF**. On a
computer, **Print / Save PDF** opens the usual print dialog directly.

## Files

| File | Role |
| --- | --- |
| `index.html` | App shell, editor controls, preview |
| `chords.js` | Music engine (`window.ChordKit`) — parsing, spelling, shapes, voicings |
| `app.js` | UI state, rendering, persistence |
| `styles.css` | Paper aesthetic plus print stylesheet |
| `html2canvas.min.js` | Vendored html2canvas 1.4.1 (MIT) — rasterises the sheet for iPad PDF printing |
| `BUILD_PROMPT.md` | The specification the app was built from |
| `CHANGELOG.md` | Version history (current: v1.3.2) |

## Run it

No build step, and no network dependencies (the one library, html2canvas, is vendored):

```bash
open index.html          # macOS
# or serve the folder
python3 -m http.server 8000
```
